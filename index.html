Fungerer offline

Dit undervisningsmateriale — også uden ChatGPT

Denne side indeholder al tekst, kode og animation. Der hentes ingen skrifttyper, billeder eller scripts fra internettet.

  1. Gem filen på din computer. Behold navnet index.html, og dobbeltklik på filen for at åbne den i Chrome, Edge, Firefox eller Safari.
  2. Lav en ekstra kopi i din kursusmappe på OneDrive, et USB-drev eller GitHub. Din downloadede kopi er uafhængig af dine ChatGPT-samtaler.
  3. Del med klassen. Upload filen til jeres læringsplatform, eller send selve filen til eleverne. De kan åbne den offline.
  4. Vil du bruge GitHub Pages? Upload filen som index.html i roden af et repository. Vælg derefter Settings → Pages → Deploy from a branch, og vælg din branch og rodmappen. Den tilgængelige indstilling afhænger af repository og konto.

Til undervisning: Brug Projektorvisning, vælg eventuelt Fuld skærm, og lad eleverne gætte resultatet, før du trykker. Tilstanden og quizsvar nulstilles, når siden genindlæses.

Fuld skærm og automatisk kopiering afhænger af browseren. Du kan altid bruge browserens zoom og markere kode manuelt.
